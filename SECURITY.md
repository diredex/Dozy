# Security Policy

## Supported Versions

Currently, only the latest version of Dozy on the `main` branch is supported for security updates. 

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to **diredex.dev@gmail.com**.

You should receive a response within 48 hours. If the issue is confirmed as a vulnerability, we will open a private draft security advisory to coordinate a fix and an announcement. 

Thank you for helping keep Dozy secure!
